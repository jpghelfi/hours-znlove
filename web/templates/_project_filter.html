dropdown of checkboxes named "project", the project-side twin of _people_filter.html. Submits with whatever form encloses it; no pick means every project. Context it expects: `projects` and `selected` (the picked ids) — pass the latter with {% with selected = … %} at the include site. It also carries the **partner** picks (checkboxes named "partner"), because a partner is a way of naming a set of projects and belongs in the control that picks projects rather than in a second dropdown beside it. The two compose on the server (AND): tick Bear to see Bear, then tick two of its projects to see just those. A partner tick is deliberately *not* the same as ticking its projects one by one — it means "whatever is under Bear today", so the link keeps working when a project joins or leaves the umbrella.
